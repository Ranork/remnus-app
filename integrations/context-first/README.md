# Context-first repository templates

Remnus Smart mode is advertised automatically through MCP server instructions. Strict mode enforces preflight for Remnus MCP mutations. These optional snippets extend the same habit to an agent's **local code tools**, which an MCP server cannot intercept.

Copy the relevant snippet into the repository's existing instruction file; do not replace established safety or project rules.

- `AGENTS.snippet.md`: Codex and other agents that read `AGENTS.md`
- `CLAUDE.snippet.md`: Claude Code project instructions

The rule deliberately excludes greetings, formatting-only work, and a single known Remnus page. Over-triggering context preparation can increase token use.
